# RMFS 흐름 관찰기

주문 도착부터 투입 대기, 작업대 배정, Pod 운반, 피킹과 복귀까지의 과정을 브라우저에서 살펴보는 관찰 도구입니다.

## 사용 방법

`index.html`을 브라우저로 열거나, 이 저장소의 GitHub Pages 주소로 접속합니다. 별도 설치나 서버가 필요하지 않습니다. 글꼴은 Google Fonts에서 불러오며, 불러오지 못하면 시스템 글꼴을 사용합니다.

- 주문량, 도착 불규칙성, 상품군 집중도와 투입정책을 바꾸어 흐름을 관찰할 수 있습니다.
- 일시정지, 10초 진행, 초기화 기능을 제공합니다.
- 주문을 클릭하면 해당 주문의 Pod와 처리 구간을 확인할 수 있습니다.

## 참고

난수와 짧은 관찰 시간에 따라 화면 수치는 달라집니다. 논문에 사용한 반복실험 결과를 그대로 재현하거나 대체하는 자료가 아니라, 운영 흐름을 이해하기 위한 도구입니다.

## 구성

- `index.html`: 화면과 시뮬레이션 코드가 포함된 단일 HTML 파일
- `.nojekyll`: 정적 파일을 그대로 게시하기 위한 설정
